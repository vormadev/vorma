# Tutorial | Step 2

## vite.config.ts

### Create empty vite.config.ts

Create an empty `vite.config.ts` in your project root:

```sh
$ touch vite.config.ts
```

---

### Add setup code

For `react`, add this to your `vite.config.ts`:

```ts
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";
import vorma from "vorma/vite";

export default defineConfig({ plugins: [react(), vorma()] });
```

For `preact`, add this:

```ts
import preact from "@preact/preset-vite";
import { defineConfig } from "vite";
import vorma from "vorma/vite";

export default defineConfig({ plugins: [preact(), vorma()] });
```

For `remix`, add this:

```ts
import { defineConfig } from "vite";
import vorma from "vorma/vite";

export default defineConfig({ plugins: [vorma()] });
```

For `solid`, add this:

```ts
import { defineConfig } from "vite";
import solid from "vite-plugin-solid";
import vorma from "vorma/vite";

export default defineConfig({ plugins: [solid(), vorma()] });
```
