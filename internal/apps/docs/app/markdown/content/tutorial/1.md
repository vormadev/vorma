# Tutorial | Step 1

## package.json

### Create empty package.json

Create an empty `package.json` in your project root:

```sh
$ touch package.json
```

---

### Set initial fields

Add the following content to the `package.json` you just created:

```json
{
	"public": false,
	"type": "module"
}
```

---

### Install packages

Use your favorite package manager to install required dependencies.

```sh
$ npm i -D typescript vite vorma
```

Install UI-library-specific packages:

```sh
# React
$ npm i -D @types/react @types/react-dom react react-dom @vitejs/plugin-react

# Preact
$ npm i -D preact @preact/signals @preact/preset-vite

# Solid
$ npm i -D solid-js vite-plugin-solid

# Remix UI
$ npm i -D remix
```
