# Welcome to Vorma.

Vorma seeks to be the world's most straightforward web framework.

Features:

- Nested, type-safe routing with parallel Go-based route loaders
- Type-safe API client with flexible request decoration options
- Critical CSS inlining
- Parallel TypeScript-based client loaders
- Hot frontend reloading at dev-time
- Built on Vite

Get started by following our [tutorial](/tutorial/1).
