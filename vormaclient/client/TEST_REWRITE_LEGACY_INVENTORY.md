# vormaclient/client Legacy Test Inventory

This file is the migration ledger for existing legacy suites in
`vormaclient/client/src`.

## Status Keys

- `mapped-initial`: intentionally reviewed at a high level and linked to a
  rewrite slice.
- `unmapped`: not yet reviewed for dedupe/removal.
- `remove-candidate`: likely redundant after contract/integration parity.
- `ready-to-delete-after-signoff`: legacy file kept in-tree with first-line
  marker `READY_TO_DELETE_AFTER_SIGNOFF`; can only be physically deleted after
  explicit signoff.
- `retained`: still needed after review.
- `removed`: legacy file deleted after replacement coverage was validated.
