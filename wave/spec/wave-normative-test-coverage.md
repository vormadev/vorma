Wave Normative Specification Test Coverage Map

Purpose

- Define the current mapping between normative requirement IDs and executable
  tests.
- Provide stable traceability so requirement coverage remains explicit as code
  and tests evolve.

Scope

- In scope: externally observable `/wave/*` runtime and tooling behavior.
- Out of scope: non-`/wave/*` behavior unless required to explain wave
  semantics.

Method

- Coverage mapping is derived from direct reading of normative requirements and
  direct reading of test implementations.
- Mapping is maintained at requirement-range granularity (`HL-*` blocks and
  their `WAVE-HLxx-*` IDs).

Coverage Summary

- `WAVE-HL01-*` through `WAVE-HL26-*` are mapped at requirement-range level.
- Mapping is range-based and can be tightened to per-test ID tagging later.
