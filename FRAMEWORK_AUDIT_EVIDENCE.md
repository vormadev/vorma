# Framework Audit Evidence (Append-Only)

## Usage

- Clean-slate evidence log for the current audit cycle.
- Historical evidence from prior invalidated cycles has been removed.
- Only append evidence for work performed after the latest integrity reset.
- Reference new evidence IDs from `FRAMEWORK_AUDIT.md` when marking a matrix
  cell `done`.

## Entry Format

- ID: `EV-YYYYMMDD-###`
- Package group
- Pass name
- Evidence
    - files reviewed
    - commands/tests run
    - findings/fixes with first-principles reasoning
